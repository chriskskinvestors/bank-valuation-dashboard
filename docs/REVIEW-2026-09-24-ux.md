Top five for the owner: UX-P0-06 (three crashes / frozen tab), UX-P0-05 (JPM ratio gap), UX-P0-14 (negative warranted price), UX-P0-02/03 (same rate, two values), UX-P0-01 (overlapping tables).

Cross-cutting themes (fix once, fixes many):

1. **Absent data is rendered three ways** (`—`, `n/a`, `$0`/`0.00%`) — sometimes
   in the same table. `$0`/`0.00%` for absent values is the fabricated-aggregate
   class and appears on Corporate Profile (CET1 0.00 % for a CBLR bank),
   Compensation (Stock/Option `$0` for JPM execs), Analyst Coverage, Capital
   Structure, Insider summary. One formatter policy is needed.
2. **JPM's FDIC ratio fields are blank** (ROAA, ROAE, NIM, NPL, NCO, leverage):
   this single data gap degrades six leaves (Corporate Profile, Financial
   Highlights, Performance Analysis, Price & Trends, Earnings key metrics,
   Interest Rate Risk) and crashes two (Asset Quality). Likely the
   multi-charter/consolidation seam (memory: multi-charter-holdcos). Numbers lane
   should own the root cause; UX needs an explained empty state meanwhile.
3. **`st.radio(horizontal=True)` renders as square checkboxes** everywhere except
   the styled nav rows (Annual/Quarterly, Period 1M…5Y, Peer set, Sort, Input
   method, Shares/Reported value, Aggregate/Details, All/Buys/Sells). Reads as a
   Streamlit DOM/CSS skew (memory: streamlit-dom-css-skew) — verify against the
   pinned Streamlit version; the checked state is a filled square, not a radio dot.
4. **Sparkline/trend columns clip their header and cells** in every ksk_table
   that has one (Home Rates & Credit, Macro Key Indicators, Credit spreads,
   Funding & Deposits): header shows `LEVE…`, `YTD …`, `Tre`/`Trenc`, sparklines cut
   at the right edge.
5. **Number formats drift across pages**: negatives as `-0.53%`, `(4.27%)` and
   `$-1.54`; market cap as `$892.0B` and `$891.98B` on one page; `$0.87B` for an
   $872M bank; `5142` vs `5,142` on one page; `Δ1Y N/A` vs `n/a`.
6. **Raw internals leak to the user**: Python tracebacks (3 views), `**= …**`
   markdown in table cells, `&amp;`, snake_case tags (`capital_raise`,
   `fmp_news`), "needs … the summarizer API", "set CENSUS_API_KEY".
